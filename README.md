# 梨园雅集 · 京剧文化互动展示

这是一个以京剧文化为主题的 React + Vite 单页网站，适合 PC 浏览，也适配手机窄屏。页面版心最大约 1700px。

## 预览和启动

当前本地预览地址：<http://127.0.0.1:5173/>

在安装了 Node.js 的电脑上，可在项目文件夹运行：

```bash
npm install
npm run dev
```

也可以双击 `启动预览.bat`。发布构建命令为 `npm run build`。

## 网站栏目

- 首页：三张主题封面每 3 秒自动轮播，右侧箭头可手动切换。
- 发展历程：五阶段图文时间线，滚动进入时呈现动画。
- 京剧流派：梅、尚、程、荀四张圆角艺术卡片，含流派详情，自动轮播间隔 4 秒；鼠标停留时暂停，舞台背景随当前选中的流派卡片同步切换，并为程派、荀派单独调整取景焦点。
- 艺术鉴赏：12 张京剧图片从右向左循环展示，图片可悬停或点击弹起；点击和键盘聚焦不会停止轮播。
- 唱腔技巧：介绍西皮、二黄、板式变化及唱念做打。
- 非遗名录：展示王珮瑜、于魁智、李维康、谭元寿及对应舞台照片。
- 京剧学习：四组入门主题配有素材库图片，可加入或移出本次浏览的学习清单；栏目间距已收紧。
- 用户中心：展示当前日期、指定主题寄语、学习进度和清单，不涉及真实账号。
- 站内搜索：搜索历史、流派、艺术鉴赏、唱腔、传承人与学习内容。
- 联系方式：整屏收尾页，包含邮箱和 QQ 联系方式。
- 悬浮戏曲小助手：支持轻点对话、拖拽和左侧吸附，桌面端约 96px、移动端约 64px；待机时会眨眼并间隔切换挥手姿态，收起后可点击贴边戏曲印章唤醒。

收尾页标题整体上移，标题区与深红页脚间使用单一分界线；快速链接覆盖全部栏目，邮箱与 QQ 标签、冒号及联系方式已统一对齐。

## 图片与资料

网站图片集中在 `public/assets`。传承人照片位于 `public/assets/inheritors`，四张学习卡片图片位于 `public/assets/learning`。唱腔说明引用中国非物质文化遗产网的京剧项目介绍，学习延伸链接来自国家大剧院与中国非物质文化遗产网。人物简介依据用户提供的文字整理。

流派卡片自动轮播间隔为 4 秒，鼠标悬停在流派区域时暂停；历程卡片每次滚动进入视野时都会重新播放进入动画。用户中心日期按当前设备日期显示，学习清单是页面交互演示状态。

悬浮小助手使用 `public/assets/doll.png` 作为待机姿态、`public/assets/doll-wave.png` 作为挥手姿态。气泡使用玉青色边框，快捷按钮分别为“查看学习指南”和“联系我”，链接到站内的京剧学习和联系栏目。
